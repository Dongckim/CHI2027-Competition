# V4 Soniox 실시간 자막

이슈: [#5](https://github.com/Dongckim/CHI2027-Competition/issues/5) · 판정: **진행 중 (노트북에서 실제 자막·번역 동작 확인, 측정 대기)** · 2026-10-21

## 가설
학회 발표를 실시간으로 쓸 만하게 자막·번역한다.

## 방법
- 흐름: 폰 → `POST /api/soniox-key` (우리 서버, 임시 키만 발급) → 폰이 Soniox WebSocket에 직접 연결. 음성은 우리 서버를 지나지 않음
- `functions/soniox-key.mjs`: 웹 표준 핸들러(Request → Response)라 호스트가 정해지면 그대로 옮김 (호스트는 V8 #9에서)
  - Soniox `POST /v1/auth/temporary-api-key`: `transcribe_websocket`, 만료 60초, `single_use`, 세션 최대 2시간
  - 기기별 시간당 6개, 서버 하루 2,000개 (메모리 카운터, 재시작 시 초기화). 진짜 하루 상한은 Soniox 콘솔 지출 한도
  - 요청 내용 로그 없음. 기기 정보는 Soniox에 보내지 않음 (`client_reference_id` 안 씀)
- `app/src/captions/captions.js`
  - `sessionContext(data, sessionKey)`: 세션의 공개 프로그램 데이터로 Soniox `context` 생성. 저자 이름·제목의 약어/합성어(VR, LLM, GuideMe)를 `terms`, 이름은 번역에서도 그대로(`translation_terms`), 제목 목록은 `text`. 10,000자 제한 안으로 자름
  - `createCaptions()`: 확정 토큰은 이어 붙이고 미확정은 바꿔 끼움. 원문·번역 각각 **마지막 3줄만** 화면에, 그 이전 텍스트는 버림. 종료 시 `clear()`
- `tests/captions/bench.html` (`.env.local`에 `SONIOX_API_KEY=...` 저장 후 `npm run bench` → http://localhost:5173/tests/captions/bench.html)
  - 세션 선택(용어집), 번역 언어(기본 한국어), 용어집 켜기/끄기(O/X 비교용)
  - 마이크 → `MediaRecorder` 120ms 조각 → Soniox `stt-rt-v5`, `audio_format: auto`. 스피커 소리를 받으므로 에코 제거·잡음 제거는 끔
  - 키는 WebSocket protocols 목록으로 보냄 (시작 메시지의 `api_key`는 2027-01-15부터 거부됨)
  - 발화자 분리(선택): Soniox `enable_speaker_diarization`. 원문에서 말하는 사람이 바뀌면 `S2:` 표시 (패널·질의응답용). 번역 쪽은 표시 없음
  - 화면 켜짐 유지(Wake Lock), 화면 꺼짐·앱 전환·연결 끊김 횟수
  - 측정값: 지연 = 녹음 시작 후 경과 시간 − 가장 최근 단어가 오디오에서 끝난 시각(`end_ms`). 처음 보이는 글자(미확정)와 확정 글자 따로, 중앙값/90%
  - 저장 없음. Stop을 누르면 자막을 지우고 숫자만 화면에 남김
- 대면 대화 모드 `tests/captions/conversation.html`: 휴대폰을 두 사람 사이에 눕히고 위쪽 절반은 180° 돌려 맞은편 사람을 향함
  - 각자 자기 쪽에서 언어 선택 (Soniox stt-rt-v5가 지원하는 60개, `app/src/captions/soniox-languages.json`, 각 언어를 그 언어로도 표시)
  - Soniox 양방향 번역(`two_way`) + 언어 식별. 발화자 분리 대신 **언어로 나눔**: 원문 토큰은 말한 언어, 번역 토큰은 번역된 언어가 붙어 오므로 (실제 응답으로 확인, en↔ko 합성 음성)
  - 각자 화면: 상대가 한 말을 내 언어로 (큰 글씨 3줄) + 내가 한 말이 어떻게 들렸는지 (작게 1줄)
  - `createConversation(a, b)`. 같은 언어 두 명은 안 됨 (그때는 일반 자막)
- 비용: Soniox 실시간 $0.12/시간, 번역 포함 (soniox.com/pricing, 2026-10-21 확인)

## 통과 기준

## 측정 기록표 (사람)
준비: CHI 2026 발표 영상 3편 (서로 다른 세션, 억양이 다른 발표자 포함), 스피커에서 1m, 휴대폰 화면 켠 채로. 각 영상 3분 이상.

| 영상 (세션·제목) | 용어집 | 지연 처음/확정 (중앙값) | 지연 90% | 이름·전문 용어 맞음 / 전체 | 한국어 번역 (1–5) | 끊김 (화면 끔 30초, 앱 전환 30초) | 메모 |
|---|---|---|---|---|---|---|---|
| 1 | O | | | / | | | |
| 1 | X | | | / | | | |
| 2 | O | | | / | | | |
| 2 | X | | | / | | | |
| 3 | O | | | / | | | |
| 3 | X | | | / | | | |

- 이름·전문 용어: 영상에서 들리는 저자 이름·시스템 이름·약어를 미리 적어 두고, 자막에 맞게 나온 개수
- 번역: 1 = 뜻이 안 통함, 3 = 뜻은 통하지만 어색, 5 = 자연스러움
- 발화자 분리: 패널이나 질의응답 영상 1편에서 켜고, 사람이 바뀐 횟수 중 `S1/S2` 표시가 맞게 바뀐 횟수, 지연이 늘었는지
- 끊김: 화면을 30초 끄거나 다른 앱으로 갔다 돌아왔을 때 자막이 이어지는지, 다시 Start가 필요한지
