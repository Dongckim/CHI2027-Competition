# V6 이동 시간·길 안내

이슈: [#7](https://github.com/Dongckim/CHI2027-Competition/issues/7) · 판정: **조건부 통과 (거리·경로 통과, 시간은 실측 전 경험값)** · 측정일 2026-10-21

## 가설
방 사이 이동 시간 추정과 휠체어 경로가 그럴듯하다. (화면: Figma "09 Getting there" — Room A → Room B, about 2–4 min, Level x → y, Step-free route)

## 방법
- 원천: CCIB 공식 "Floorplans & capacities" PDF (결정 [003](../decisions/003-venue-from-ccib-floorplans.md))
- `npm run data:venue -- <pdf>` (`data/scripts/venue-ccib.py`, pdfplumber) → `data/venue/ccib.json`
  - 표: 구역 108개의 면적·가로·세로·높이·배치별 수용 인원
  - 도면: 방 사각형·문 표시·엘리베이터·에스컬레이터 아이콘의 벡터 좌표 → 미터 (축척은 방 크기를 표와 맞춰 계산)
  - 방 테두리(`rect`, 미터): 파란 방 사각형, 여러 방이 한 사각형이면 표의 폭으로 나눔. 표 치수와 2m 안 (P2 211+212가 1.6m로 최대)
  - 그래프: 문·복도·엘리베이터·에스컬레이터 지점 190개, 연결 212개. 거리는 이미 미터
- `data/venue/chi2026.json`의 `rooms`: 피드 방 43개 → 구역 ID
- `app/src/venue/route.js`: 문에서 문까지 최단 경로. 결과 = 거리(m), 시간 범위(분), 지나는 층, 엘리베이터/에스컬레이터
  - 기본(걷기): 층 이동은 에스컬레이터 (도면에 계단 표시가 없어 계단은 없음). 에스컬레이터로 안 이어지는 곳만 엘리베이터
  - 휠체어: 엘리베이터만, 속도 0.9/0.7 m/s
  - 시간 범위: 걷기 1.3/0.9 m/s + 에스컬레이터 층당 20–40초, 엘리베이터 대기 30–120초 + 층당 10초
  - 경로 안내(`stops`): 복도 이름 대신 눈에 보이는 랜드마크 순서. 꺾는 곳마다, 직선은 25m마다 하나 (WC > 에스컬레이터 > 엘리베이터 > 방 번호 순), 다른 정지점과 12m 안이면 생략
    - 예: 117 → Escalator P1→P2 → Banquet Hall → 212 → 211 / 휠체어: 117 → Elevators → 114 → Elevator P1→P2 → 211
- 브라우저 확인: `npm run bench` → http://localhost:5173/tests/venue/bench.html (Figma 09 배치를 흉내 낸 확인용 페이지, `?from=P1-117&to=P2-211&wheelchair=1`)
- 확인: `node tests/venue/try.mjs 111 211 [--wheelchair] [--json]`, 테스트 `tests/venue/route.test.mjs`

## 통과 기준
1. 손 계산 5개 구간 오차 범위 이내
2. 휠체어(계단 없는) 경로가 계단·에스컬레이터를 지나지 않음
3. 해마다 교체 가능한 구조

## 판정
**조건부 통과.** 손 계산 5/5, 휠체어 경로에 에스컬레이터 0회, 플래너 연결 완료. 평면도는 이 정도로 마무리 (2026-10-21). 조건: ① 시간은 경험값이라 실측 필요 ② 복도 중심선·P0/M1 문·오디토리움 안쪽은 손 입력(`estimate`) ③ 계단 데이터 없음
