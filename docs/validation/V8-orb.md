# V8 원 안 질문의 대비 (2026-11-20, fix/orb-contrast)

## 가설
원 안의 질문은 장식이 아니라 핵심 내용이다(사용자). 흰 글자를 유지하고 원 안쪽을 거의 검은색으로 채우면, 8종족 모두에서 4.5:1을 넘는다. 종족 색은 테두리·빛·바깥 링으로도 충분히 보인다.

## 방법
- `.arc-orb`(지도 12·15·18·19·23·24·25와 10 Building이 같이 씀)
  - 안쪽: `--arc-orb-fill` #0E0E12
  - 종족 색: 2px 테두리(85%), 바깥 빛 20px(35%), 안쪽 가장자리 빛 12px(28%)
  - 바깥 링(`arc-holo`, `arc-ring`)과 10의 진행 링은 그대로
- 새 검사 `tests/qa/orb-check.mjs`(qa:auto의 `orb`)
  - 지도 12와 10에서 화면 루트의 `data-tribe`를 8종족으로 바꿔 가며 잰다.
  - 질문 글자 획 밑 배경 가운데 나쁜 2%를 기준으로 4.5:1 이상인지 본다.
  - 15·18·19·23·24·25는 같은 부품이라 a11y-check가 각 화면의 종족으로 잰다.
- 대비 예외(`a11y-exceptions.json`의 contrast 항목)와 `data-contrast-exception` 표시를 지웠다. 질문에는 검사용 `data-orb-question` 표시만 남겼다.

## 통과 기준
8종족 × (12, 10) 모두 4.5:1 이상. a11y-check는 예외 없이 통과.
