# 003 학회장 거리는 CCIB 공식 평면도 PDF에서 뽑는다

날짜: 2026-10-21 · 단계: V6 (#7)

## 결정
- 방 사이 거리·층 정보는 CCIB가 공개한 "Floorplans & capacities, CCIB | 2026" PDF에서 뽑아 `data/venue/ccib.json`에 저장하고 커밋한다. CHI 공식 피드에 이어 두 번째 보조 원천 (ROR은 002)
- PDF는 커밋하지 않는다 (CCIB 저작물). URL과 sha256만 기록하고, 다시 뽑을 때는 받아서 `npm run data:venue -- <pdf>`
- 거리는 저장 시점에 이미 미터. 앱은 최단 경로만 계산하고 단위 변환·좌표 변환을 하지 않는다
- 피드의 방 → 학회장 구역 연결은 `data/venue/<edition>.json`의 `rooms`(방 키 → 구역 ID). 학회장은 해마다 바뀌므로 venue 파일을 교체하면 된다 (chi2027 = Pittsburgh, 평면도는 따로 구해야 함)

## 이유
- 피드의 평면도(`floors[].mapImageUrl`)는 비스듬한 입체 그림이라 축척이 없다. 거리를 잴 수 없음
- CCIB PDF의 층 평면도는 위에서 본 벡터 도면이고 같은 PDF에 방 치수 표가 있다. 도면 위 방 크기와 표의 치수가 2.4% 안에서 맞으므로 축척(0.4163 m/pt)을 믿을 수 있다
- 5개 층이 같은 틀로 그려져 있고, 엘리베이터 3개가 모든 층을 관통하므로 층끼리 0.4m 안으로 맞출 수 있다

## 대안
- 피드 입체 그림에 손으로 핀 찍기: 축척이 없어 거리 불가
- 층별 고정값(같은 층 4분, 다른 층 7분): 지금 플래너의 임시값. 118호↔134호와 111호↔117호를 같게 봄
- CCIB에 CAD 도면 요청: 가장 정확하지만 시간이 걸림. 현장 실측과 함께 다음 단계 후보
