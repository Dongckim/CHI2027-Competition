2. 저장 (IndexedDB, 7일 테스트)

3. 예약 배너

30초 배너를 누르고 화면을 켠 채 기다리기 → 2분 배너를 누르고 화면을 끄거나 다른 앱으로 갔다가 3분 뒤 돌아오기.

4. 마이크

5. 화면 꺼짐 방지 (Wake Lock)

켠 뒤 2분 동안 손대지 않기 → 화면이 안 꺼지면 O. 앱 전환 뒤 돌아와서 상태 확인.

6. 알림

iPhone은 홈 화면에 추가해서 연 앱에서만 권한을 물을 수 있습니다 (공유 → 홈 화면에 추가).

푸시: 권한을 받은 뒤 버튼을 누르고 바로 홈 화면으로 나가거나 화면을 끄기. 알림이 오면 눌러서 돌아오기.

7. 키보드

맨 아래 입력창을 누르고 1초 기다리기. 입력창이 키보드 위에 보이면 O.
