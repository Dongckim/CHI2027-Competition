# ARC — Academic Research Compass

**One sentence about your research, one line through CHI.**

A mobile web companion for CHI attendees, built for the CHI 2027 Digital Experience Competition. Not an official CHI or ACM app.

🚧 Work in progress — currently in technical validation.

## Data

Uses the [official CHI programme data](https://chidigitalexperience.org/programme-data/). Programme data © ACM CHI, licensed under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

Institution names are linked to [ROR](https://ror.org) records (CC0).
